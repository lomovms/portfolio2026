## Общие интеракции

- Фиксированная шапка: логотип, Back в кейсе, звук, Let's Talk, Menu/Close.
- Выпадающее меню справа: отдельные светлые карточки навигации и рассылки; чёрная карточка Labs. Подложка затемняется; анимированное открытие.
- Контакт — переход к почте / общему контактному разделу, отдельного route в публичном меню нет.
- Плавная прокрутка, крупные появления слов, параллакс медиа, движение камеры, pointer interaction в 3D.
- Футер: адрес в Бристоле, социальные сети, две почты, рассылка, Labs, переход на следующую страницу.
- Футер визуально трёхчастный: адрес слева, соцсети и почты в среднем столбце, крупная рассылка справа; снизу тёмная полоса следующей страницы и маркеры +.
- Экспертиза About: яркий синий полноэкранный раздел с веером четырёх карт и сложной белой контурной графикой. Локальная графика карт нарисована самостоятельно в SVG.

- Внешние клиентские сайты и labs.lusion.co — отдельные продукты, а не внутренние страницы основного сайта. Сохраняются как внешние ссылки.

## Визуальная система

Светлый холодный лавандовый фон; почти чёрный текст; нейтральный гротеск; примерно 5vw поля. При ширине 1743px логотип расположен x84/y60, hero x87/y224, ширина 1568, radius около 22px. Вступительный текст x488/y50, около 42px, три строки. Сцена имеет тёмный фон, глянцевые синие, чёрные и серые шестилучевые трубчатые объекты с отверстиями. Камера видит плотный объёмный кластер. Знаки + по нижнему краю, scroll hint по центру. Кнопки — компактные капсулы. About — тёмный первый экран с тысячами частиц, дальше светлые информационные секции.

## План реализации

React Router + типизированные данные 19 кейсов. Один Canvas с R3F View для многих областей (ограничение WebGL-контекстов); общая библиотека оригинальных процедурных сцен. GSAP ScrollTrigger для scrub/появлений, переход страницы, hover/drag. Адаптивная типографика, touch-жесты, клавиатура, reduced-motion, обработка недоступного WebGL. Русские описания — краткий самостоятельный пересказ.
